# Code of Conduct

## Our Standard

This project expects respectful, constructive, and professional collaboration.

Examples of behavior that contribute to a positive environment:

- Giving actionable, respectful feedback
- Assuming good intent while discussing technical disagreements
- Keeping discussions focused on the work
- Being considerate in conversations about sensitive mental health topics

Examples of unacceptable behavior:

- Harassment, insults, or personal attacks
- Discriminatory or exclusionary language
- Trolling, bad-faith arguing, or repeated disruption
- Sharing private or sensitive personal data without consent

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, pull requests, and other contributions that do not align with this code of conduct.

## Reporting

If you experience or witness unacceptable behavior, open a private security-style report through the contact path described in `SECURITY.md`.
